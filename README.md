## Ideas for future posts

### Accessible Focus Indicators: Stop Hiding outline: none

> Why it fits: You covered Buttons vs. Links and Headings. Focus management is the immediate next technical bridge for keyboard users interacting with those elements.
> The Angle: Many designers hate default browser focus rings and strip them out without replacing them. This post can showcase how to design and code focus styles that look modern and brand-aligned using CSS properties like outline-offset and :focus-visible.
> Proposed Title: Focus Indicators Don't Have to Be Ugly

### The Anatomy of an Accessible Modal Dialog

> Why it fits: Your Accessibility Checklist gives a high-level view; a deep dive into modals offers a real-world component study. Modals are notoriously difficult to get right.
> The Angle: Walk through the non-negotiable requirements for a modal: focus trapping, restoring focus on close, handling the Escape key, using <dialog> natively vs. custom ARIA roles, and preventing background scrolling.
> Proposed Title: Building Modals That Don't Trap Keyboard Users
